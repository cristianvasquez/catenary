# Open work

The contracts (spec/manifest.hs, spec/ui-manifest.hs) define target behavior. This file holds decisions, implementation gaps and defects. Do not change a contract merely to match the code.

Evidence labels distinguish source checks from historical reports. A historical report comes from an earlier review or test run. It is not verification of the current tree. Reproduce it before a change. Remove a row when its item is done. Each row names a current file and a completion condition. A source check does not prove runtime behavior.

## Verification gaps

- **Read budget compliance:** not established. `pnpm test:perf` (`packages/rdf/test/perf/read-budget.perf.ts`, p50 of 20 samples) is diagnostic on a local machine. On 2026-10-13 a diagnostic run gave `refresh/figures` a p50 of 35 to 41 ms and a maximum of 48 to 52 ms against `readBudgetMs = 50` (manifest §11.3). No controlled benchmark runner exists. Done when a dedicated runner or reserved CPUs run `pnpm test:perf` with `CATENARY_PERF_ENV` set, and its report shows each span within the budget or a listed exception. The functional stability is a separate matter: the 2026-10-13 failures of `read-budget.test.ts` (58 and 71 ms under a load average of 8 to 11) came from elapsed-time assertions. Since 0fqy, `pnpm test` asserts no elapsed time.

- **Clipboard e2e under load:** the scenario "raw RDF paste, graph consent, Copy as RDF, reference paste, and cut mark" (`scripts/e2e/clipboard-shapes.cjs`) failed with "text/plain holds the Turtle of the copy" (kata 85wz, 2026-10-13, and on ymtv base 284d0c0). Suspected product race, not proven (812s): Ctrl+C writes the system clipboard twice without order, the token in `modeler/src/browser/diagram/clipboard.ts` (`writeText`) and the Turtle with the custom type in `diagram-configuration.ts` (`writeSystemClipboard`). An instrumented run under CPU load ended with the token in text/plain and no custom type. The scenario now waits for the token of the current copy, checks again after the paste and prints the clipboard call log. Done when one copy makes one ordered clipboard write, or a test establishes the order of the two writes. A passing rerun does not close this entry.

- **View URL backend reset:** `pnpm verify --e2e` failed the view-URL scenario (now `scripts/e2e/editors.cjs`) with `ECONNRESET` on its isolated backend. A full retry passed. Cause unknown. The historical artifacts are gone. Not reproduced in 2 full and 23 focused runs (wzx4). The scenario now fails at once on a CLI error and keeps `diagnostics.json` with the backend exit code and signal. Done when a recurrence gives the cause from those diagnostics and a fix. A passing rerun does not close this entry.

- **Shape-undo timeout:** one full browser run of the shapes view scenario (now `scripts/e2e/clipboard-shapes.cjs`) timed out waiting for `unnamed shape 1` to disappear after Ctrl+Z. A rerun passed. Cause unknown. The historical artifacts are gone. Done when a recurrence shows whether focus or command delivery failed, and a fix. A passing rerun does not close this entry.

- **Trace panel (UI §8.13):** unit tests cover the tracer, the traced store, an edit trace and the validation trace (`packages/rdf/test/trace.test.ts`). - **Browser completion seams (atrp):** no acknowledgement exists for (1) a hidden panel that processed a revision and decided not to read, (2) a gesture that sends nothing (Del, the bend-handle click, a refused bend edit), (3) Ctrl+C in a page without clipboard permission. `scripts/e2e/panels-canvas.cjs` uses a flush (two rAF and macrotask turns), a `requestTypeHints` barrier and an unchanged backend revision. - **Untested interactions:** note editing across windows and viewport changes, concept-drag dimming, target-handle overlap and instance-violation display need current checks. Older manual results are not proof for the current build.
- **Windows:** `.github/workflows/windows.yml` runs the tests of paths, files, the watcher and Git on Windows, a static check of the package and `scripts/smoke-desktop.mjs` on `Catenary.exe` and `Catenary.cmd`. It passed on `windows-latest` (Windows Server 2025) on 2026-10-07. The smoke test does not check window input, keyboard layouts, conpty or SmartScreen. The package substitutes a drive-list stub and the browser keyboard layout for unavailable native modules. It requires `git.exe` on PATH for Source Control.
- **Windows profiles:** `Catenary.cmd` gives no `--user-data-dir`, so the first process uses the default Electron profile, not `profileDir(workspace)`. Check whether a second launch or New Window on the same workspace then starts a second backend on the same files. The profile base on Windows is `%USERPROFILE%\.config\catenary\profiles`, not `%APPDATA%`.
- **Windows install folder:** Theia parses the plugin folder (`THEIA_DEFAULT_PLUGINS=local-dir:<path>`, set by `catenary-main.js`) as a URI. An install folder with `#`, or with `%` and two hex digits (for example `C:\C#\Catenary`), gives a wrong plugin folder, and Source Control does not load.
- **macOS:** no macOS runtime test exists. The package (`scripts/package.sh darwin-*`) uses the same drive-list stub and browser keyboard layout. It has only an ad hoc signature, so Gatekeeper blocks the first start of a downloaded copy. Check the start, filesystem writes, Git and the terminal on Intel and Apple silicon. Decide whether to sign and notarize with an Apple Developer ID.
- **Linux package:** the release package keeps the native modules of the build on Ubuntu 22.04. It is not tested on other distributions.
- **Electron:** use a real window. Headless Electron gives no working window: its main process exits and leaves its backend running, so a headless test cannot check the single-instance lock. A second `desktop.sh` launch on an open workspace must focus the open window: not verified with a real window. Historical test backends sometimes stopped with SIGPIPE during rebuilds. Reproduce with process logs before attributing a cause.
- **Side panel widths:** `side-panel-sizes.ts` is not verified in a tiling window manager (Niri). Start the Electron app in a half-width column twice and check that both side panels keep their width. No browser test resizes the window yet.
- **RDF 1.2:** base-direction literals lack end-to-end verification. Do not claim full support from term-key and writer checks alone.
- **Scale:** routing cost on larger diagrams remains unmeasured. Small-view timings are not performance guarantees.
