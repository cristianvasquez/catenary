# Open work

The contracts (spec/manifest.hs, spec/ui-manifest.hs) define target behavior. This file holds decisions, implementation gaps and defects. Do not change a contract merely to match the code.

Evidence labels distinguish source checks from historical reports. A historical report comes from an earlier review or test run. It is not verification of the current tree. Reproduce it before a change. Remove a row when its item is done. A source check does not prove runtime behavior.

## Verification gaps

These entries record earlier runs on different trees. Their counts are not additive. No entry certifies the current working tree.

- **Review-fix verification:** `pnpm verify --e2e` passed check (7.3 s), test (769 passed, one opt-in benchmark skipped, 9.5 s), build (9.1 s) and browser tests (17/17, 68.0 s). Both manifests typecheck. Logs: `/tmp/catenary-verify-fFKW0w`. Regression tests cover cached selection epochs, RPC mutation counts and final batches on Pause, Clear and resume. The browser test checks Pause with an unpolled full-view read. First model-update latency remains a paint opportunity, not proof of screen presentation.

- **Shape-undo timeout:** one full browser run timed out waiting for `unnamed shape 1` to disappear after Ctrl+Z. The focused rerun passed (1/1), followed by a full pass (17/17). Cause unknown. Check keyboard focus and command delivery if it recurs. Failure artifacts: `/tmp/catenary-shapes-LNvZK5`.

- **Historical verification (742 tests):** `pnpm verify --e2e` passed check (4.2 s), test (742/742, 9.3 s), build (9.3 s) and browser tests (16/16, 59.2 s). Logs: `/tmp/catenary-verify-7gLuos`. Browser coverage includes edge stroke zoom, hidden-panel reads and save-only requests. The scoped-read trace test now requires no instance-origin span for view counts. `pnpm check:manifests` also passed for both manifests.

- **Historical verification (test cleanup, 724 tests):** `pnpm verify --no-build --e2e` passed check (13.8 s), test (724/724, 43.5 s) and browser tests (14/14, 129.1 s, 3 at a time), merged with main, after `pnpm build:browser`. `CI=1` (2 workers): test 40.8 s. The Electron build did not run: the container has no `ffmpeg.node` for Electron. GHC was absent, so manifest typechecking was skipped. No browser test clicks the "Show more" row: backend paging has a unit test. The new `ci.yml` has not run on GitHub yet.

- **Trace panel (UI §8.13):** unit tests cover the tracer, the traced store, an edit trace and the validation trace (`packages/rdf/test/trace.test.ts`). The browser regression in `pnpm e2e` checks metric rendering, model-input sampling, Clear and stopping backend recording with Pause. A historical manual check also saw tracing stop when Problems replaced Trace. Hiding Trace has no browser regression. A CLI connection that calls `rpc setTracing true` keeps the trace on until it calls `rpc setTracing false`.

- **Browser coverage:** the instance workflow was removed because it was flaky. Instance forms, notes, undo/redo and save lack that browser coverage. Preserve lower-layer tests. Add browser checks only for wiring and gestures.
- **Untested interactions:** note editing across windows and viewport changes, concept-drag dimming, target-handle overlap and instance-violation display need current checks. Older manual results are not proof for the current build.
- **Windows:** `.github/workflows/windows.yml` runs the tests of paths, files, the watcher and Git on Windows, a static check of the package and `scripts/smoke-desktop.mjs` on `Catenary.exe` and `Catenary.cmd`. It passed on `windows-latest` (Windows Server 2025) on 2026-10-07. The smoke test does not check window input, keyboard layouts, conpty or SmartScreen. The package substitutes a drive-list stub and the browser keyboard layout for unavailable native modules. It requires `git.exe` on PATH for Source Control.
- **Windows profiles:** `Catenary.cmd` gives no `--user-data-dir`, so the first process uses the default Electron profile, not `profileDir(workspace)`. Check whether a second launch or New Window on the same workspace then starts a second backend on the same files. The profile base on Windows is `%USERPROFILE%\.config\catenary\profiles`, not `%APPDATA%`.
- **Windows install folder:** Theia parses the plugin folder (`THEIA_DEFAULT_PLUGINS=local-dir:<path>`, set by `catenary-main.js`) as a URI. An install folder with `#`, or with `%` and two hex digits (for example `C:\C#\Catenary`), gives a wrong plugin folder, and Source Control does not load.
- **macOS:** no macOS runtime test exists. The package (`scripts/package.sh darwin-*`) uses the same drive-list stub and browser keyboard layout. It has only an ad hoc signature, so Gatekeeper blocks the first start of a downloaded copy. Check the start, filesystem writes, Git and the terminal on Intel and Apple silicon. Decide whether to sign and notarize with an Apple Developer ID.
- **Linux package:** the release package keeps the native modules of the build on Ubuntu 22.04. It is not tested on other distributions.
- **Electron:** use a real window. Headless Electron gives no working window: its main process exits and leaves its backend running, so a headless test cannot check the single-instance lock. A second `desktop.sh` launch on an open workspace must focus the open window: not verified with a real window. Historical test backends sometimes stopped with SIGPIPE during rebuilds. Reproduce with process logs before attributing a cause.
- **Side panel widths:** `side-panel-sizes.ts` is not verified in a tiling window manager (Niri). Start the Electron app in a half-width column twice and check that both side panels keep their width. No browser test resizes the window yet.
- **RDF 1.2:** base-direction literals lack end-to-end verification. Do not claim full support from term-key and writer checks alone.
- **Scale:** routing cost on larger diagrams remains unmeasured. Small-view timings are not performance guarantees.
- **Manifests:** GHC checks only names and types. No test checks a `law_<name>` clause yet, and the stubs are not linked to the TypeScript code. Next step: one vitest per law, for the history model (spec/manifest.hs §5), IDs (§1.3) and the label and cardinality equations first. Primitives without a law are still prose. Do not claim contract certification from the typecheck.
