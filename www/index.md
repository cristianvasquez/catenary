features:
  - title: Canvases first
    details: You author on a canvas. Each canvas is one view of the model. Open several canvases to explore the facets of a design problem.
  - title: Shapes and data together
    details: Make the instances first, or the shapes first. SHACL shapes give the fields and the checks. A violation shows at once, so the two converge.
  - title: Files are the model
    details: A workspace is a folder of RDF files. Each edit writes a file and can make a Git commit. Import files from outside and lock them.
  - title: Write it up
    details: Embed a view in a Markdown document. Export the document with the diagrams as SVG and share it.
